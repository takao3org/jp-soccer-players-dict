## 概要

海外クラブに所属する日本人選手、および日本代表(A代表・年代別代表)の選手名を
変換候補に出すためのIME辞書です。「姓」「名」「姓名(人名)」の単位で登録して
あり、外国人選手など姓名の一部がカタカナの場合はカタカナ部分/漢字部分も
個別に変換できるようにしています。

## 収録ファイル

対象選手の範囲ごとに2種類、IMEの形式ごとに4種類(Gboardのみ`.txt`と
`.zip`の両方)、合計10ファイルを配布します。

| ファイル名 | 対象 |
| --- | --- |
| `players_overseas_*` | 海外クラブ所属の日本人選手 + 日本代表(A代表) |
| `players_all_*` | 上記 + 年代別代表(U-23〜U-15) |

拡張子の前の `msime` / `googleime` / `mozc` / `gboard` が、対応するIMEを
表します。`msime`/`googleime`/`mozc`の内容はほぼ共通で、各IMEが読み込める
形式に合わせてヘッダー行のみ変えています。

`gboard`だけは形式が異なります。Gboardのユーザー辞書インポートには
「姓」「名」「人名」のような品詞を登録する仕組みが無く、3列目は品詞の
代わりにロケール(`ja-JP`)として扱われるため、`gboard`版は品詞情報を
持たないただの単語登録(同じ読み・単語の組は1行に重複排除)になります。
また、GboardへのインポートはテキストファイルそのものではなくZIP圧縮
したファイルを使うため、`players_overseas_gboard.zip` /
`players_all_gboard.zip`も同梱しています(`.txt`は内容確認用です)。
なおこのZIPインポートの形式はGoogle公式のドキュメントが見当たらず、
コミュニティでの実例に基づくものです。

## インストール方法

まずこのリポジトリをクローン、またはZIPでダウンロードして展開してください。
その中から、使っているIMEと登録したい範囲(overseas/all)に合うファイルを
1つ選びます。

### Microsoft IME

1. タスクバーの「あ」や「A」のアイコンを右クリックして「設定」を開く
2. 「辞書/学習」の「ユーザー辞書」欄にある「編集」から
   「Microsoft IME ユーザー辞書ツール」を起動する
3. 「ツール」メニューから「テキストファイルからの登録」を選ぶ
4. `players_all_msime.txt`(または `players_overseas_msime.txt`)を選択して開く

### Google日本語入力

1. タスクトレイのGoogle日本語入力アイコンを右クリックして「辞書ツール」を開く
2. 「管理」メニューから「新規辞書にインポート」を選ぶ
3. 「参照」で `players_all_googleime.txt`(または `players_overseas_googleime.txt`)を選択
4. 文字コードは「UTF-8」、形式は「Google 日本語入力」を選ぶ
5. 辞書名(例: サッカー選手)を入力して「インポート」

### Mozc

Linux(ibus-mozc / fcitx-mozc)の場合も同様です。

1. Mozcの設定(プロパティ)から「辞書ツール」を起動
2. 「管理」メニューから「新規辞書にインポート」を選ぶ
3. `players_all_mozc.txt`(または `players_overseas_mozc.txt`)を選択
4. 文字コードは「UTF-8」、形式は「Mozc」を選ぶ
5. 辞書名を入力して「インポート」

### Gboard

Android版Gboardの個人辞書(ユーザー辞書)へのインポート手順です。

1. `players_all_gboard.zip`(または `players_overseas_gboard.zip`)を
   端末に転送する
2. Gboardの設定 →「単語リスト」→「日本語」を開く
3. 右上の「︙」から「インポート」を選び、転送した`.zip`ファイルを選択する
4. 取り込みが終わるまで待つ(件数が多い場合、画面が止まって見えることが
   あります)

前述のとおりこの形式では品詞情報を持てないため、登録される単語は
すべて品詞なしの単語になります。
